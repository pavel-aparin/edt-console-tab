# edt-console-tab Встроенный терминал для EDT

Плагин добавляет кнопку, которая открывает терминал (консоль git-bash) прямо внутри EDT.
Плагин является надстройкой над стандартным Eclipse TM Terminal. Его главное отличие — при открытии терминала рабочая директория автоматически устанавливается в корневую папку текущего проекта.

## Установка

1. Откройте в EDT **Справка → Установить новое ПО**.
2. Добавьте репозиторий:

   ```text
   https://pavel-aparin.github.io/edt-console-tab/
   ```

3. Выберите **EDT Console Tab**, завершите установку и перезапустите EDT.
